# Skills

- [`create-experiment`](create-experiment/SKILL.md) — Uses an adaptive Socratic dialogue to clarify an experiment's purpose and decision criteria, then initializes its minimal repository record and hands off detailed design to `prepare-experiment`.
- [`create-protocol`](create-protocol/SKILL.md) — Converts messy source material or records of past runs into canonical, reusable protocol templates with normalized quantities, structured metadata, linked dependencies, and deterministic calculations when needed.
