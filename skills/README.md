# Skills

- [`create-bench-sheet`](create-bench-sheet/SKILL.md) — Renders a prepared experiment's run manifest into a standalone human-readable bench sheet (markdown plus PDF) with instantiated quantities, layout, fill-in fields, and a confirm-before-you-start checklist.
- [`create-experiment`](create-experiment/SKILL.md) — Uses an adaptive Socratic dialogue to clarify an experiment's purpose and decision criteria, then initializes its minimal repository record and hands off detailed design to `prepare-experiment`.
- [`create-protocol`](create-protocol/SKILL.md) — Converts messy source material or records of past runs into canonical, reusable protocol templates with normalized quantities, structured metadata, linked dependencies, and deterministic calculations when needed.
- [`prepare-experiment`](prepare-experiment/SKILL.md) — Collaboratively develops an initialized experiment into an executable run manifest by challenging the design, instantiating canonical protocols, planning analysis before execution, and running integrated preflight validation, then hands off to `create-bench-sheet`.
